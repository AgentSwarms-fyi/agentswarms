# Screenshots used by the project README

The root `README.md` references these five files by exact name. Replacing one
updates the README with no other change.

| File                                 | Shows                                                                       |
| ------------------------------------ | --------------------------------------------------------------------------- |
| `swarm-canvas.png`                   | Swarm canvas — node palette, a multi-agent graph, the node inspector        |
| `bi-dashboard.png`                   | BI Workspace — a published multi-page dashboard with KPIs and charts        |
| `agent-chat-visual-bi.png`           | Agent Chat — a chart answered from connected tables, with the SQL as source |
| `agent-chat-document-generation.png` | Agent Chat — generated PowerPoint / Word with preview and download          |
| `developer-workspace-notebook.png`   | Developer workspace — a sample notebook running on a server kernel          |

Guidance for retaking them:

- **Full-window, dark theme.** The rest of the set is dark; one light shot looks
  like a mistake.
- **Use the sample data.** Screenshots showing real customer names or internal
  figures cannot be replaced later once the repo is public.
- **Keep them under ~400 KB each** (PNG, ~1900px wide is plenty). They load on
  every visit to the repo front page.
